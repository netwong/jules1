# Carbon Atom Visualization Web App

## Description

This project is a simple web application that visualizes the movement of electrons in a simplified 2D model of a Carbon atom. It aims to provide a basic educational tool to understand atomic structure.

## Purpose

The main purpose is to demonstrate:
*   A central nucleus.
*   Electron shells around the nucleus.
*   Electrons orbiting within these shells (2 in the first shell, 4 in the second for Carbon).

## Technologies Used

*   **HTML:** For the basic structure of the web page.
*   **CSS:** For styling the page and the visualization elements.
*   **JavaScript:** For the logic of the animation, using the **HTML5 Canvas API** for drawing.

## How to Run

1.  Clone or download the repository.
2.  Navigate to the project directory.
3.  Open the `index.html` file in any modern web browser.

No special compilation or build steps are required.
