# Carbon Atom Visualization Web App

## Description

This project is a simple web application that visualizes the movement of electrons in a simplified 3D model of a Carbon atom. It aims to provide a basic educational tool to understand atomic structure from a 3D perspective.

## Purpose

The main purpose is to demonstrate:
*   A central nucleus in 3D space.
*   Electron shells (conceptual paths) around the nucleus.
*   Electrons orbiting in multiple 3D planes within these shells (2 in the first shell, 4 in the second for Carbon).
*   Interactive camera controls to view the model from different angles.

## Technologies Used

*   **HTML:** For the basic structure of the web page.
*   **CSS:** For styling the page.
*   **JavaScript (with Three.js):** For the 3D logic, animation, and rendering.
*   **Three.js:** A 3D graphics library for creating and displaying animated 3D computer graphics in a web browser.

## How to Run

1.  Clone or download the repository.
2.  Navigate to the project directory.
3.  Open the `index.html` file in any modern web browser.
4.  Ensure your browser supports WebGL for the 3D visualization (most modern browsers do).

No special compilation or build steps are required.
